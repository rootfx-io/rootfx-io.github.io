# ELBE Cookbook Recipes

This repository contains the example ELBE build recipes used in the book:

"Building Embedded Systems with Linux, Raspberry Pi and ELBE"

The examples demonstrate how to build reproducible embedded Linux systems using the ELBE (Embedded Linux Build Environment) and Debian.

## What is ELBE

ELBE is an embedded Linux build environment originally developed by Linutronix.  
It allows developers to generate Debian-based root filesystems and system images from declarative XML configuration files.

This approach enables reproducible system builds and structured system customization.
